# 抖音带货短视频文案脚本

## 概述

为电商商品（重点：鞋服类目）批量产出可投放的抖音短视频推广文案与口播脚本。核心能力：商品卖点提取 → 同行打法参考 → 多角度批量产出 → 合规审查 → 迭代替换。

## 工作流

### 1. 获取商品信息

- 抖店商品链接（haohuo.jinritemai.com）用 WebFetch 直接抓取，通常能拿到标题、品牌、材质、鞋头/鞋跟款式等参数。
- 用户补充的参数（如跟高 5.5CM）必须写入文案，且只作为产品参数表述（"5.5cm 粗跟"），不写成效果承诺（"穿上增高 5.5cm"）。
- 关键卖点缺失（颜色、跟高、材质）时，先问用户或抓详情页，不臆造。

### 2. 参考同行打法

- 用 WebSearch 搜"抖音 + 品类 + 文案/口播/钩子"（例：抖音 玛丽珍 带货文案），看 2-3 篇结果提炼同行高频句式。
- 同行可复用的钩子库与角度库见 references/playbook.md，产出时按商品卖点挑选组合，不生搬硬套。

### 3. 产出文案

- 默认 20 条一组，每条 ≤50 字（含话题标签另计，标签 1-2 个为宜）。
- 按 4-6 个角度分组输出（显高/舒适/设计感/场景/情绪钩子等），每组标注角度名，方便用户按组反馈。
- 每批结尾给 1-2 条风险标注：指出哪几条用了边缘表述、卡审时怎么替换。

### 4. 合规审查（每条必过）

逐条检查 references/playbook.md 的合规清单：
- 无极限词（最/第一/唯一/顶级等绝对化用语）
- 无动物皮材质描述（用户品牌硬性要求，即使商品是皮鞋也只写"单鞋""软面"等）
- 增高/显高只做视觉表述（"显腿长""拉长比例"），不做功效承诺
- 医疗、功效、贬低同类等表述一律规避

### 5. 迭代替换

用户说"换一批/再换"时：保留上一批的角度框架，只替换句式和意象；用户点名某几条好时，分析被选中条目的共性，下批向该风格收敛。

## 输出格式

```
**角度名**
1. 文案正文 #标签 #标签
2. ...
```

分组输出 + 结尾风险标注。批量任务（30 条以上）或用户要求存档时，落一份 Markdown 文件到用户资料目录（D:\WorkBuddy资料），并在回复里给出文件路径。

## 品牌偏好（XIEFURN 鞋夫人）

- 风格：年轻、有生命力、画面感强，善用食物/视觉意象（黑糖树莓、焦糖布丁、可颂、油画等）
- 鞋款线：德训鞋、玛丽珍、阿甘鞋；每款配色配套独立文案
- 平台：抖音/千川，规避审核风险优先于表达张力
