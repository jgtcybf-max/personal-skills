# 抖音带货文案：同行打法库与合规清单

## 一、同行高频钩子（2025-2026 实测可复用）

### 数字钩子
- 具体增高/跟高数字：跟高 X cm（作参数）、"4cm 增高""鞋底高 4.5cm"
- 行为数字："暴走 20000 步不累脚""穿上第七天""追问三次链接"
- 对比数字："五五分变三七分""腿长+3cm 视觉"

### 痛点钩子
- 身高焦虑："150+ 小个子狂喜""小个子听劝"
- 撞鞋焦虑："拒绝撞鞋""别人都在要链接"
- 舒适焦虑："新鞋不磨脚""没有磨合期""宽脚救星"
- 头重脚轻："不像老爹鞋踩两条船"

### 视觉/意象钩子
- "上脚秒变大长腿""开了瘦脚滤镜""像从油画里走出来"
- 食物意象：可颂、奶咖、焦糖、黑糖（暖色系鞋款尤佳）
- "脚感像踩在棉花上/云朵上"

### 场景钩子
- 通勤/约会/上学/citywalk/下楼拿快递/遛娃
- "衬衫配它上班，裙子配它约会，一双鞋打两份工"
- "追公交也来得及"

### 社交验证钩子
- "同事都在问链接""女明星穿去走红毯""评论区全在问"

## 二、角度分组模板（20 条标准配比）

| 角度 | 条数 | 说明 |
|------|------|------|
| 核心参数卖点（跟高/增高/厚底） | 4-5 | 参数作事实表述，配视觉描述 |
| 舒适/脚型友好 | 3-4 | 不磨脚、显脚小、宽脚友好、轻便 |
| 设计感/风格 | 4-5 | 配色、五金、鞋型、氛围意象 |
| 场景百搭 | 3-4 | 2-3 个具体场景并列 |
| 情绪/社交钩子 | 3 | 同行高频句式，结尾用 |

## 三、合规清单（逐条过）

### 必须规避
1. **绝对化用语**：最、第一、唯一、顶级、王牌、销量冠军、国家级
2. **动物皮材质**：牛皮/羊皮/真皮/猪皮一律不写（品牌硬性要求）；替代写法：软面、织物、网布、单鞋
3. **功效承诺**：不写"穿上增高 Xcm"“立增 X 厘米身高”，改写"跟高 Xcm""显高""拉长腿部线条"
4. **医疗/健康**：不写矫正、治疗、缓解足部疾病
5. **贬损对比**：不点名竞品，不写"比 XX 强"

### 低风险替换
| 边缘表述 | 替换为 |
|----------|--------|
| 立增 5cm | 5.5cm 粗跟，显高不累脚 |
| 最舒服 | 舒服到不想脱 |
| 全网第一 | 评论区都在问的那双 |
| 真皮质感 | 软面有质感 |

### 体感表述（一般可过审，卡审时替换）
- "五五分变三七分" → "比例明显变好"
- "腿长+3cm" → "视觉腿长直接拉一截"
- "暴走两万步" → "暴走一整天"
