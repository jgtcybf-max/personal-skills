# 重写模板

重写版提示词一律用下面的骨架，不要自创结构。目标：**前 300 字说完核心意图，全文 ≤ 800 字，否定句 ≤ 5 条。**

## 一、总骨架

```
基于@视频1做局部编辑：<一句话说清只改什么、其余全保留>。

【参考】@图片1 <用途>；@图片2 <用途>；……（每张都必须有用途，且说明它们描述的是同一主体）

【与原片的 N 处不同，逐条改，其余照原片】
1 <部件>：原的 A 消失，换成新的 B，外观后果 C。
2 ……

【保留】<人物/动作/背景/光影/节奏，用名词短语，不复述原片>

【硬约束】<最多 3 条，只留会毁片的>
```

## 二、差异条目怎么写

一条合格的差异条目必须同时有三段：

| 段 | 作用 | 写法 |
|---|---|---|
| 旧的要死 | 否定原片残留 | 「原鞋那条深棕隐形细拉链消失」 |
| 新的要生 | 给出新形态 | 「换成浅灰金属螺旋齿，从靴口后中 V 形最低点到后跟上缘」 |
| 看得见的差别 | 让模型能自检 | 「金色拉链头停在最上端，接一条同色皮质拉片垂下约 12cm」 |

常见失败：只写中段。模型会把新特征叠在原结构上，出现「双拉链」「两个鞋底」这种增生。

## 三、顺序规则

1. 最显眼的差异排第一（观众一眼能判断对错的），通常是颜色、材质、整体轮廓
2. 最容易出错、用户最在意的排第二（本例是鞋底结构、后拉链）
3. 位置类描述用「相对原片」的坐标系（正后方中线、靴口下方 3cm、外侧偏前），不要用「左边右边」

## 四、分段时的追加句

同一份主提示词，每段末尾各加一句「本段重点」，不复述全篇：

```
本段重点：<该段独有的视角> + <该视角下必须被验证的特征>
```

例：
- 段1：本段重点：手拿靴子展示和单脚穿靴时，整体轮廓、颜色、材质、鞋底侧面厚度必须一眼看出是参考图那双。
- 段2：本段重点：抬脚露底时完整呈现鞋底纹路与实心足弓；最后转身背对镜头时，后中拉链、金色拉链头、皮质拉片清楚可见。

## 五、常见任务的最小写法

**换物（商品替换）**：差异清单是主体，参考图 3–5 张，必须含「正面 + 侧面 + 背面 + 底面」四向中至少三向。

**换背景**：不写差异清单，改写「只保留主体的哪几处接触关系」，其余全部交出去。否则模型会为保住原背景而牺牲主体。

**换人**：不写五官细节（视频模型不支持写实人脸参考），只写体态、发型轮廓、服装；人脸一致性交给原片。

**视频延长**：不重写全部，只写新增时段的内容 + 一句衔接要求；生成长度选「新增部分的秒数」。

**去水印**：先确认原片真有水印。有的话只写一句「去除画面中所有文字与角标，保持地面/墙面/边缘连续」；没有就删掉整节。

## 六、写完自检

- 数否定句（不/无/禁止/避免/不得），> 5 条就删
- 数字母与汉字，> 800 字就砍
- 找「逐帧」「不随帧变化」「纹路不漂移」这类词，全删
- 检查每个 `@图片N` 是否都写了用途
- 检查有没有要求「文字清晰可读」——除非该区域 ≥ 500px
- 检查有没有要求「脚踝/膝盖/身高整体位移」——除非接受比例变形
