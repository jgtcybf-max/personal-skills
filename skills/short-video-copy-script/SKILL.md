# Short Video Copy Script

Use when the user provides a short-video link, transcript, screenshots, or described reference and asks for analysis or a new Douyin/TikTok-style script. Reproduce the underlying persuasion mechanism and rhythm, not distinctive wording, claims, or a creator's identity.

## Workflow

1. Gather transcript/subtitles, on-screen text, shot descriptions, comments, and product context. A link alone may be inaccessible; state that limitation and do not invent source details.
2. Extract audience tension, hook, insight/contrast, proof, payoff, CTA, pacing, point of view, and visual actions. Separate reusable structure from category-specific facts.
3. Translate to the target product. Map taste/refreshment to sensory experience, ingredients to formula/actives, eating occasion to use occasion, satisfaction to visible or felt benefit, and repeat purchase to routine/ritual.
4. Draft one primary script plus two alternate hooks when useful, with timing, visuals, spoken lines, subtitles, and edit notes.
5. Check audience fit, evidence needed for claims, prohibited wording, and missing source material.

## Default output

- **Source pattern**: 3-6 observations labeled observed or inferred.
- **Transfer map**: source element -> target beauty/personal-care element.
- **Script**: table columns `time`, `shot/action`, `voiceover/dialogue`, `on-screen text`, `sound/edit note`.
- **Posting copy**: title, caption, and 3-5 hashtags.
- **Variants**: alternative first-three-second hooks.

Use a 1-3 second hook, one message per beat, concrete sensory/use detail, and one low-friction CTA. Default to 30-45 seconds if duration is unspecified.

## Claims and originality

Do not promise treatment, cure, permanent results, guaranteed efficacy, or absolute superiority. Use qualified language such as “帮助改善” or “使用后感觉”. Do not make ingredient, testing, certification, before/after, or safety claims without substantiation; mark what needs verification. Do not copy exact sentences, catchphrases, personal details, or a misleadingly similar persona. If the source cannot be inspected, say the analysis is a hypothesis and request transcript or screenshots for a faithful second pass.
