# 续跑断点与任务级生成政策

重启、交接或用户要求暂停核历史时先读本页。本页不授予新生成权限，当前用户指令优先于旧执行包和默认480→1080流程。

## 链接到执行包

本用户已指定后续默认素材目录为`C:\Users\TTT\Desktop\小蒋灰底图`，排除`不用查看`及其子目录；产出目录为`C:\Users\TTT\Desktop\ai每日产出\M月D号`，北京时间，具体归属日期按任务约定。用户临时指定覆盖默认。只发抖音链接时沿用这些路径匹配并出方案，按既有审核约定获批后再生成。

用户已指定固定素材目录和排除目录时，直接按已知范围匹配，遍历前按准确名称剪枝排除目录及其子目录（本用户为“不用查看”），不先读取再过滤。按作品ID查现有源片及媒体核验；已有最高可用无水印原片且无需重下时复用。确需下载时沿用下载技能，核实际可用最高档、尺寸/码率和水印，不用升采样冒充更高清。

保留完整静音视频与完整独立MP3；若生成参考删段或裁切，另存实际生成用静音视频，并保留对应剪辑音频/映射，不能把整段MP3直接配到删段视频。执行包明确链接、源片、实际引用、商品款色、原音、风险和验收；新方案遵从当前审核约定，已获该方案生成授权的无需再问开始。

## 核对断点与桌面交接

先用 `scripts/resume_card.py --record <task-record.json> --out <本任务/续跑>` 生成只读卡片，读取最新政策、各色最新真实任务、缺失路径、待核受理和下一步提示。用户禁止访问的目录用 `--exclude-dir` 传入，卡片不访问该目录的路径。卡片只压缩主记录，不能替代当前UI或生成预检；有矛盾才展开相应原始证据，不每次重新审完整聊天和所有历史文件。

若确切下载、原音和已有审核均在本地，优先继续本地缺口，不先激活桌面或恢复输入助手。主记录仍记“生成中”但已发现下载时，核节点下载链后更新记录，不再提交。

1. 指定一名桌面操作者。用户要求暂停核历史或确需接管桌面时，向原操作者发送停止指令并确认已停止；只发消息但仍在点击不能算暂停。普通只读监测不打断唯一执行端。子代理只读本地媒体、记录或准备文件，不抢桌面。
2. 读取最新用户原话、`generation_policy`、`task-record.json`和最近证据。旧交接只帮助定位，不能把旧“接下来生成”当当前授权。主记录有矛盾先记明并核真实任务。
3. 每款色区分：本地素材齐备 → 已上传 → 已连线草稿 → UI提示词及参数已核 → 单次提交/受理未知 → 已受理 → 平台终态 → 已下载 → 画面已审 → 原音技术完成 → 听审 → 归档。前一项不证明后一项；文件名叫定稿不证明UI已填入。
4. 核当前画布、节点和实际结果，只补缺失。不因重启、等待或输入返回超时重按生成。受理未知先追查原节点/账单/任务列表，仍未知则保留占位并停止该款色新增提交。

## 质量条件和生成授权分开

默认两阶段仍适用于已授权完整流程；用户新限制只影响当前任务。480画面通过不能越过“仅测试一条”“生成过的不要再生成”或亲自审核等约束。已有款色被禁止新增时，可继续同任务下载、审核、合音和归档，不能把1080、高清重渲染或重试改名后视为未重复。

建议`generation_policy`包含用户原话、生效时间、去重范围、1080许可、重试许可、允许首次款色及已有任务处理范围。更新它不删除既有提交和费用。白名单是必要条件，仍须核是否刚被其他执行端受理；旧`allowed_first_colors_remaining`不能覆盖新`tasks`事实。

提交前对同款色核：

- 已受理任务和失败提交均保留；状态未知占用生成资格。下载副本、本地合音和审核证据不是新平台任务。
- 暂无平台ID，用节点ID＋提交时间记真实身份；不伪造ID。父480用真实平台ID或`parent480_key`，节点名回退必须唯一并匹配商品/颜色。
- 主记录只设一个写入者；写前重读版本/哈希。状态写入失败时先保留提交证据，不能再点击“补一笔”。只读检查器不能替代当前UI/授权核对，也不提供跨操作者锁。
- 交接只带：最新用户政策/主记录路径及SHA256、当前任务/节点ID、已下载确切路径、未完成步骤、仍有效的输入通道/到期时间（只有需要桌面时）。不复制整段历史当新任务，也不将已提交改为待生成。

本技能的`check_generation_policy.py`是可选只读预检，结果有记录哈希、读取时间和检查时间；它不点击、不写主记录、不确认模型参数、不授予付费权限。缺少关键任务政策、非法阶段、提交身份不全或存在歧义时返回需核对，不能把未阻止解释为已授权。明确限制已被满足仅表示可继续做当前UI核验。

## 焦点与输入恢复

窗口切换、屏幕缩放、弹窗或最小化恢复后重新核当前窗口、焦点、原图尺寸和截图原点。输入前做一次无付费、可见的验证，粘贴后回读实际目标字段。工具`ok`不能证明提示词、重命名或参数已正确改变。

输入助手记录到期时间；临近到期先完成当前可确认动作，再按原权限方式续开，不能自动无限续期。UAC由用户操作。manifest的`highestAvailable`或令牌拒读只是线索，不能直接写成“管理员已证”。用户已授权无响应时自行恢复/重开应用的，核云端保存、在途任务后可执行；不更改权限或绕过系统确认。重开后重核任务、焦点和输入通道。

## 下载、审核与日归档

已完成节点尽早下载。唯一桌面操作者继续下一色时，本地审核、动作时序、原音替换和归档可由子代理并行；主记录单人合并。源片和商品未变就复用签名有效的准备结果，只补疑点，不重做全解码和全目录盘点。

用户指定每日产出目录时，按任务约定的日期依据和时区归档；本批使用实际生成日、北京时间M月D号，分别记录提交、完成及下载时间，跨日下载不擅改生成日期归属。保留原下载，另存对应MP3的原声版；每个版本标明真实分辨率、画面结论、音频技术/听感状态与SHA256。`待听审`不能改写为通过，错误颜色或新增镜头不能因生成成功而通过。费用未知仍是未知，不等于0；平台等待、下载等待及账单待核分别记录。
