# 画布视频编辑操作证据与易错处

本记录来自2026-11-14的小蒋无限画布操作。界面会变化，先截图，不能照抄旧坐标、PID或句柄。

## 已验证

- 先上传原视频和商品图到画布。原视频右侧连接口 → 引用该节点生成 → 视频，可创建引用原视频的生成节点。
- 新节点默认模型可能不支持当前任务；当时切到视频编辑、Seedance 2.5 0.7x后，同时接收原视频和多张商品图。模型名称是历史证据，不是固定必选。
- 图节点选中后左右两边出现连接口。**从右边口拖到生成节点左边输入口**，连接既有商品图，不需要再次上传。
- 当时成功接入6张鞋款整体图和1个视频。引用列表最初堆叠，点击堆叠后展开为参考图1—6及参考视频1。6张是当次用量，不是模型上限。
- 提示词填写后输入区会向下扩大，生成按钮位置随之改变。每次按当前截图定位，不能沿用填写前的位置。
- 成功后视频节点出现播放器；选中节点上方工具栏的向下箭头是“下载到本地”，打开的是**选择文件夹**对话框。
- 下载时出现带随机尾缀的临时文件，完成后为MP4。历史输出720×1278、24fps、约9.06秒，源片1080×1920、30fps、9.33秒，因此UI“跟随/自动识别”不保证输出完全相同。

## 480原生的证据边界

用户后来要求以后先用480原生测试。历史首版实际用720标准，**尚未完成480原生端到端实测**。下一次调用应在实际参数面板选中并截图核对480原生，再在成片元数据核实实际尺寸；不要把本记录当作480已验证。

用户进一步要求480审核通过后生成1080正式版，并明确本次只做流程。**480到1080的操作入口、高清重渲染及1080输出也尚未端到端实测。** 这些是后续执行规则，不是已完成结果；下一次实际执行时核查可用选项和真实输出，不能据此宣称已成功生成1080。

后续声音规则：用户明确超级编导内无法加原视频配音、不需要尝试。1080下载成功后直接走本地原音轨替换与同步检查，见 [local-audio.md](local-audio.md)；不要再测试生成面板“上传音频”入口。本轮仅维护流程，没有制作原声最终版。

## 桌面输入

- 普通Windows MCP优先；当时超级编导管理员权限导致普通点击无效，临时受限输入助手才成功。需要时读取 [上传技能的权限说明](../../superdirector-canvas-upload/references/desktop-input.md)，调用其已安装脚本；不复制一份权限代码到本技能。
- 实际全屏3840×2160的截图曾缩成1920×1080，图中坐标乘2才是物理坐标。裁剪截图还需加裁剪原点。新助手使用物理像素，不额外除150%缩放。
- 旧助手仅调用 `SetForegroundWindow`，不保证还原最小化窗口。2026-11-14新增助手会尝试恢复并回读实际前台句柄，但恢复行为尚未实测；仍须确认能看到目标窗口后再输入。
- 用户或另一个聊天同时移动鼠标时，先停止输入并协调桌面占用。每组动作前确认焦点，尤其原生文件框出现后避免把文本发到别的应用。
- 顶部铅笔是重命名，不是生成配置。双击生成节点可打开配置。网页播放器三点菜单是下载/播放速度/画中画，不能误认为全屏按钮。
- 系统UAC如出现由用户亲手确认；不改UAC或系统权限。任务结束停止临时助手，保留超级编导窗口与画布。
