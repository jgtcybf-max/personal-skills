# 原视频、目标商品图与成片对照

## 检查方法

1. 读取源片和输出的实际尺寸、时长、帧率、音轨，并检查全片可解码。记录480原生是UI选项还是已核实输出像素，两者分开。
2. 按每段镜头取帧，补充转身、抬脚、接触、遮挡和切镜前后；可以用 [review_media.py](../scripts/review_media.py) 一次解码准备24帧总览、首两帧、尾帧和已知重点段，调用见 [speed-workflow.md](speed-workflow.md)。数量随内容调整。看联系表后只放大可疑处，再观看这些位置的动态；抽样图不能证明所有帧均无变形，首两帧也不能由第一张总览缩略图代替。
3. 将成片与商品多角度图比较，而不是只和旧鞋比较；商品图真实细节优先于文件名、标题或提示词描述。
4. 可疑闪变先定位源片对应镜头。输出时长或帧率变化时，同一事件时间可能提前，不能只按同一秒做像素比较。

## 女鞋和长靴检查项

| 项目 | 观察内容 | 不通过或需标注的证据 |
| --- | --- | --- |
| 整体鞋款 | 颜色、鞋头、鞋帮/筒高、轮廓、鞋跟、厚底和齿纹 | 仍是旧款尖头/薄底、目标粗跟消失、两脚变不同款 |
| 识别细节 | 靴口弧线、拉链、金属标志、鞋面结构、材质和反光 | logo变化、内外侧混淆、拉链方位错误、皮面过亮 |
| 透视与尺度 | 脚转向时的内外侧、鞋底、鞋跟、大小和地面接触 | 漂浮、鞋底不贴地、鞋头/鞋跟膨胀、腿长改变 |
| 动作与遮挡 | 整理靴口手指、裤腿入靴、交叉腿、步行、抬脚 | 手穿靴筒、鞋与腿断开、前后遮挡反转 |
| 连续一致性 | 同一镜头及切镜后是否同款，细节是否闪变 | 旧鞋重现、logo漂移、鞋筒或鞋底突然变形 |
| 保留内容 | 人物服装、包、室内物品、构图、动作/剪辑节奏 | 无关物体改变、新镜头、时长偏差；写具体位置 |

## 判定与说明

- **通过**：已检查范围内整体款式、结构、关键动作与遮挡符合目标；列出实际检查范围。480下不可分辨的细纹和小logo列为待复核，不能因此宣称商品精确一致。
- **有瑕疵**：整体替换成立，但有局部logo、反光、褶皱或轻微节奏偏差；给具体秒数、影响和修正方向。不能把此状态当商品细节验收通过。
- **不通过**：换错款、核心结构错误、旧鞋残留、明显穿模/肢体异常或持续闪变。保存测试证据，在当前授权范围内决定是否调整提示词/引用重测，不自动升级清晰度以掩盖问题。

## 两阶段审核

- 480原生是测试阶段。结论“通过”才进入1080正式生成；“有瑕疵”或“不通过”不进入。用户指定亲自审核时，以其结论为阶段条件；否则代理根据实际检查判定，不用反复要求用户确认。
- 480下看不清的小logo和细纹标为待1080复核，可以在已检查的整体鞋型、动作、遮挡合格时判定测试通过；已可见的logo变形、穿模等错误不能这样豁免。
- 1080重新生成可能改变细节，必须比较商品图、原片与通过的480版本。既复核480待确认的细节，也复核原已通过的鞋型和动作，不能只读分辨率就交付。
- 正式版说明写对应的480文件/批次及通过证据，并单独写1080结论。保存两个版本。正式版有新问题时标清，不能把480的“通过”复制给1080。
- 1080下载后按 [local-audio.md](local-audio.md) 在本地加回原视频配音；不在超级编导内尝试。原声最终版还要听开头、中间和结尾，核对同步、音量、尾句完整性及没有双重配音，确认画面尺寸保持。不能把“存在音轨”或“画面审核通过”当作原配音审核完成。

原视频同目录的 `_说明.md` 应包含：

```markdown
检查结论：有瑕疵（例，按实际改）
阶段：测试01（480原生）/ 正式01（1080下载版）/ 正式01（1080最终原声版）
对应测试片：正式版填写通过的480文件名/批次；测试阶段写本片
实际设置：本阶段实际清晰度 / 视频编辑或实际高清模式 / 模型名 / 1条
实际输出：宽×高、帧率、视频时长、音轨；未知写未核验
本次引用：参考视频1=…；参考图1=…，图2=…
一致：…
问题：约x.xx秒，…；约y.yy秒，…
与原片比较：动作/镜头/时长…；可疑转场原片是否存在…
待复核：480下不能确定的logo或纹理；1080阶段写复核结果…
原配音：最终版填写来源、替换方式、对齐方式、同步及音量检查；前两阶段写待本地合成
下一步：480通过后进入1080；不通过先修正；1080下载审核后本地加原配音并复核，最终通过后交付（按实际范围填写）
```

历史987案例仅供判断误报：目标圆头厚底替换成立，但约1.9秒银色标志拉成条纹，输出时长缩短；黑场和绿边白闪在源片中也存在。不要把这些具体秒数或鞋型写入其他任务的结论。
