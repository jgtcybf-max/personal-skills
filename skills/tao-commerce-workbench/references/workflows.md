## 1. 女鞋选款与货源核价

从真实竞品商品和价格出发，比较款式、成本与货源，形成可行动的候选表。

触发：这家店哪些鞋值得做；找这双鞋的货源；同款比价；选款核利润。

所需输入：
- 参考商品或店铺链接，或清晰商品图
- 要研究的平台、范围和时间段
- 已知货号、目标售价与成本资料；没有则标待补
- 可用后台/供应商报价或用户提供的数据

执行：
1. 用商品ID确定样本，分别标出完整店铺、直播商品卡或单品范围；记录价格、状态、链接和采集时间。 路由：`douyin-shop-sales-ranking`、`ego-browser`。
2. 有明确七日字段或同商品ID的七日间隔快照才计算七日销量；否则交付当前快照，累计销量与互动仅作各自字段。 路由：`douyin-shop-sales-ranking`。
3. 需查看鞋款图片时导出原始主图/详情；通过真实 Ego 查看1688候选，核对鞋型、颜色尺码、起订量、阶梯价、运费与现货，不因图片近似直接判同款。 路由：`douyin-product-image-export`、`ego-browser`。
4. 使用同一订单口径列出到手收入、货品、履约、平台/佣金、售后和获客成本；列建议样品、待核证事项与淘汰原因。 路由：`spreadsheets:Spreadsheets`。

交付：
- 候选鞋款对照表：商品ID/图/来源/采集时刻/售价/报价条件/已知成本/证据等级
- 先做样品、补信息或暂不做的清单及理由

验收：
- 同一商品只按稳定ID关联；同图不同ID不合并销量
- 七日、累计、估算、未知分列，缺失不填0
- 利润使用用户真实成本或明示情景，不能把报价当成交价
- 没有创建订单、支付、联系供应商或开启付费查询

外部服务边界：公开网页使用真实 Ego；LinkFox需要账号、API Key并消耗算力。本工作流默认不调用付费接口、不采购。

## 2. 同款审核与商品资料包

核对拼多多/抖音SKU，整理可追溯商品图、规格与审核表，减少货号和颜色串款。

触发：新品上百亿审核表；拼多多ID匹配抖音同款；整理商品主图和详情图；鞋模板填图。

所需输入：
- 本批拼多多商品ID和可用抖音商品链接
- 用户指定工作簿或当前用途明确的模板
- 货号、颜色、尺码等实际规格资料
- 需要的主图/详情图范围

执行：
1. 先读模板表头、说明与示例，确定一商品一行或逐SKU，并确认所谓uid是SKU规格ID还是其他字段。 路由：`pdd-douyin-review-fill`、`spreadsheets:Spreadsheets`。
2. 以本批商品ID查询规格，与抖音标题、鞋型、主图和同规格SKU交叉核对；无法确认的记录留待核验。 路由：`pdd-douyin-review-fill`、`ego-browser`。
3. 导出需要的原分辨率主图和详情，按商品/来源归档；需要图表模板才插入图片，保持一张图与商品列的映射。 路由：`douyin-product-image-export`、`shoe-template-image-fill`。
4. 保存独立成品工作簿，校验长ID文本、规格对应、图片与链接；商品文案只用已确认事实，未确认皮革/PU等成分不写成事实。 路由：`spreadsheets:Spreadsheets`。

交付：
- 已保存的审核工作簿与未确认条目清单
- 带来源清单的商品图片资料包
- 供文案/视频后续复用的已确认商品事实表

验收：
- 商品ID、SKU ID与规格逐项对应，不把店铺/账号ID填到SKU栏
- 保留原模板与原始下载文件，成品可打开且图片不串列
- 文字、颜色、尺码与货号保持用户原写法；疑似错误不擅改
- 只准备/填表，不代提交平台审核，除非本次另有明确要求

外部服务边界：模板填表与图片整理不需要LinkFox等付费服务。平台页面需要登录时由用户在Ego完成；不取得隐藏数据。

## 3. 参考视频转女鞋脚本

拆解参考镜头与声音，转成能直接拍或生成的女鞋镜头方案。

触发：这条视频怎么拍的；把这个视频改成我的鞋；拆镜头写女鞋脚本；根据参考做换鞋提示词。

所需输入：
- 参考视频本地文件或链接
- 目标鞋款图片/货号与已知卖点
- 要实拍脚本还是AI替换提示词；从当前请求判断
- 需要保留的动作、构图、配乐/口播及交付格式

执行：
1. 需要本地素材时下载参考并核对时长/尺寸；保留原视频，默认抽取音频为MP3。 路由：`douyin-video-download`。
2. 逐镜检查素材来源、动作、镜头、字幕包装、画中画、声音事件和切点；不能仅凭口播或封面臆测画面。 路由：`rea-video`。
3. 把可复用结构改写成目标鞋款实拍分镜；有商品图时编写保留原视频动作构图的换鞋提示词，先描述目标外观与表面质感，不认定未知材质。需要完整剧本、原帧故事板和自包含剧情提示词时才使用video-master。 路由：`douyin-shoe-video-recreate`（换鞋/实拍）；`video-master`（完整剧本故事板）。
4. 对照原片核验镜头顺序、时间、鞋款露出、人物与环境连续性；需要静音/原音轨时单独输出，真实成片才进入媒体核验。 路由：`douyin-shoe-video-recreate`。

交付：
- 按时间码排列的镜头表、拍摄动作与女鞋脚本
- 按用户需求附AI替换提示词、原音轨MP3或静音视频
- 来源判断及仍需确认的镜头/材质

验收：
- 每个镜头对应实际参考时间段，事实与制作判断分开
- 鞋子结构、颜色和已知卖点不因改写而变更
- 只输出提示词时不声称生成了成片；参考音轨授权与使用范围按实际任务
- 付费生成前落实具体模型/任务范围；估算、实际扣费、退款和净消耗分别记账

外部服务边界：下载/拆解和提示词不等于付费生成。dLazy、Linkpix、超级编导等实际云端生成仅按本次明确授权执行，不因安装导航自动提交。

## 4. 每日剪辑派单与挂车排期

所需输入：
- 本批货号与参考链接或已完成视频
- 每条或全局剪辑要求
- 发布时另需目标账号、文案、商品ID/链接和具体排期

执行：
1. 只需整理任务时直接生成可复制微信的文字；当天货号不从昨天推断，单条例外按本次明确指代处理。 路由：`daily-editing-tasks`。

## 5. 女鞋种草选题与图文

基于真实样本和产品事实做小红书选题、封面与正文，再按要求生成素材或发布。

触发：这双鞋做一篇小红书；找同类爆款笔记；女鞋种草文案；图文封面和排版。

所需输入：
- 目标鞋款图、真实特点与穿搭场景
- 账号受众/目标；已在上下文明确可直接沿用
- 需要研究、文案、图片还是发布的范围
- 参考链接、已有草稿或可用素材

执行：
1. 用真实Ego查看当前可访问的小红书样本，记录链接、采集时间与可见互动；轻量选题先看3—5篇，按任务范围扩展。 路由：`xhs-content-ops`、`xhs-explore`、`ego-browser`。
2. 提炼标题钩子、封面结构、穿搭场景与评论需求；区分可见事实与推测，不照搬原作者文案，也不把累计互动当近期增长。 路由：`xhs-content-ops`、`xiaohongshu-ops`。
3. 完成目标鞋款标题/正文与视觉方案。需要卡片排版时用现有卡片技能；明确要求生成图片才使用相应图像能力，并核对尺寸、文字和鞋款一致性。 路由：`xhs-note-creator`、`baoyu-xhs-images`、`gbro-cover-design`。
4. 只按当前要求交付草稿、图片或发布；实际发布用Ego核对账号、图片顺序、可见性与时间，再检查成功页/作品列表。 路由：`xhs-publish`、`ego-browser`。

交付：
- 有来源样本依据的选题与标题正文
- 按请求提供封面/图片方案或实际图片文件

验收：

## 6. 经营利润与投放复盘

以真实订单和广告报表核对销售、退货与获客成本，给出下一轮可检验动作。

触发：昨天卖得怎么样；这批投放值不值；按鞋款复盘利润；广告花费和订单对不上。

所需输入：
- 本次明确日期范围的订单/退款/结算/广告报表
- 货品、物流、平台、佣金、售后等实际成本口径
- 货号/商品ID与素材ID映射；缺失则仅在可证范围分析
- 对比周期和目标指标；没有目标时以事实诊断为先

执行：
1. 先核对报表时区、币种、时间范围、指标定义与订单去重键；销售额、支付额、结算收入、退款和净收入分别列出。 路由：`spreadsheets:Spreadsheets`。
2. 按同一订单/结算口径核算贡献：实际净收入减货品、履约、平台佣金、可归属广告及其他成本；退款已在净收入扣除时不能重复扣。未知成本标缺失，另列情景。 路由：`spreadsheets:Spreadsheets`。
3. 把素材或货号的曝光、点击、成交、退款与花费放在同一期间比较；公开热度只能补充观察，不能代替后台转化或实际ROI。 路由：`spreadsheets:Spreadsheets`、`xhs-content-ops`、`ego-browser`。
4. 区分确定问题、可能原因与下一轮实验。每个实验只改变关键变量，写目标、预算或资源上限、观察窗口和停用条件；没有授权只交建议，不改广告账户。 路由：`spreadsheets:Spreadsheets`。

交付：
- 按日期/货号/素材的经营与利润表，含公式和来源
- 3项以内优先动作，每项含证据、预期、观察窗口和验收方式
- 缺数据清单及可执行的补数办法

验收：
- 同周期、同币种、同订单/结算口径，退款与成本不重复扣
- 广告归因ROI与财务利润分开；平台ROAS定义照原报表记录
- 不把空白当0，不把情景利润当已实现利润
- 公式无错误，重点区域可读；未授权不增预算、启停计划或修改投放

外部服务边界：优先本地报表与已授权后台可见数据，不假定开通第三方分析接口。广告调整、营销发送、付费数据查询需按本次具体授权执行。
