# 创作者数据和评论/@通知

本参考合并自 `white0dew/XiaohongshuSkills` 的独有用途。原源码完整保存在 `C:/Users/TTT/.local/share/skill-sources/RedBookSkills-20261114`，不再单独注册 RedBookSkills。

## 创作者内容数据表

用户要求分析自己的笔记表现时，先核对当前 Ego 账号。打开官方创作者中心的数据/内容分析页面，记录可见的时间范围与指标定义。可能出现的字段包括曝光、观看、封面点击率、点赞、评论、收藏、涨粉、分享、人均观看时长和弹幕；并非每个账号/内容类型都会返回全部字段。

- 区分作品累计值、选定日期范围内值与平台估计值。缺失字段留空并标注不可用。
- 按作品稳定 ID 和链接关联记录；标题相似不证明同一作品。
- 页面提供导出时通过 Ego 保存；否则提取页面可见表格，记录采集时间与样本范围。
- 用户没有授权后台访问或页面需验证时交给用户，不从其他浏览器抽取登录态。

上游 `scripts/cdp_publish.py` 的 `get_content_data()` 和 `content-data --csv-file` 提供字段与 CSV 逻辑参考，原实现依赖 Chrome CDP，不能直接当作已适配 Ego 的执行器。

## 评论和 @ 通知

用户要求查看评论和 @ 通知时，通过当前 Ego 官方会话打开通知页，核对“评论和@”等当前界面入口。区分通知类型、关联作品、评论作者、评论内容和时间；记录实际已读条数，未加载内容标明缺口。

读取通知不授权回复、点赞或私信。需要回复时转 `xhs-interact`，按用户明确目标和文案执行。

上游 `get_notification_mentions()` 和 `get-notification-mentions` 会读取通知页触发的 `you/mentions` 数据，可作实现参考。Ego 中以正常页面实际请求与可见内容为依据，不猜造授权参数或绕过登录。

本次仅保留方法与字段，未登录账号验证上述后台数据或通知采集。
