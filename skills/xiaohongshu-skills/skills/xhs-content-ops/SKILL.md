# 小红书复合研究与运营

先读 [本机 Ego 执行方式](../../references/local-ego-execution.md)。

## 竞品、选题和热点

1. 从用户现有信息确定主题、账号与受众。
2. 用 xhs-explore 取样，记录排序、时间、链接及采集时刻。轻量任务可先看3—5篇，按用户范围扩展。
3. 读取正文和实际图片/视频，记录标题钩子、封面、结构、观点、话题和评论信号。未核验图像时标明。
4. 比较可见点赞、收藏、评论，区分累计值、当前快照和明确的时段数据；没有匹配历史样本时不推算增长率。
5. 输出共同点、差异、可借鉴结构和具体选题，区分事实与判断，不照搬表达。单次热门搜索不能证明持续趋势。

## 复盘与交付

- 定位、内容支柱与长期策略读 xiaohongshu-ops。
- 自有创作者后台曝光、观看、点击率、转粉、评论/@通知读 [专项数据参考](../../references/creator-data-and-notifications.md)，通过 Ego 读取当前账号可见数据；公开互动数不能替代后台数据。
- 根据研究先完成标题、正文、图片方案和来源。图像排版读对应创作技能；用户要求发布才进入 xhs-publish，需要互动才进入 xhs-interact。

上游多步 CLI 和专用浏览器实现保留作参考，不宣称已完成 Ego 自动化。执行以当前页面和落盘证据为准。
