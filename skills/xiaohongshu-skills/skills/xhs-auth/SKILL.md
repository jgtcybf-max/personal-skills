# 小红书认证管理

先读 [本机 Ego 执行方式](../../references/local-ego-execution.md)。

1. 在本任务 Ego 页面打开官方站点或创作者中心，核对可见账号与登录状态。
2. 已登录且账号正确时报告状态；只读检查不触发退出或切换。
3. 需要登录时展示登录页，按 Ego 指南 handOff，由用户扫码、输入验证码或完成验证；不索取密码、不自动发送短信。
4. 用户确认完成后恢复同一空间，核对昵称/账号及页面标识。二维码出现不等于登录成功。
5. 明确要求退出或换号时，核对目标账号并操作官方入口，验证状态变化；不清理整个浏览器配置。

只检查当前 Ego 会话，不导入其他浏览器登录态。上游 CLI 认证命令只作参考。
