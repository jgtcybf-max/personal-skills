# 小红书发布

先读 [本机 Ego 执行方式](../../references/local-ego-execution.md)。

## 准备

- 从已有信息确定目标账号、标题、正文、图片或视频、发布方式和时间。缺关键内容时先整理草稿，再询问缺失项。
- 用户只给网页链接时，用 Ego 提取实际正文与内容图片，记录来源并整理稿件；懒加载图片检查真实 data-src，排除占位图和网站图标。
- 图文需图片、视频需可读视频文件；使用素材绝对路径。通过 Ego 文件选择器/文件输入上传，核对数量、顺序和预览。
- 标题、正文和媒体上限以页面反馈为准。超长时保留原意拟改稿，不机械截断或擅自修改要求逐字保留的内容。

## 图文与视频

1. 打开官方创作者中心并核对账号，进入对应页签。
2. 上传本次素材，等待预览及处理完成，再填标题、正文与话题。
3. 按用户要求设置封面、可见范围、原创声明与时间；页面缺少设置时明确报告。相对排期先换算为明确日期、时间与时区，用户未指定时按北京时间理解。
4. 核对账号、文字、媒体顺序和时间。已有明确发布授权且内容确定时提交；只要求准备或草稿时交付可审阅结果。
5. 用成功页、作品管理或草稿列表中的对应条目验证。超时/结果未知时先查原作品，避免重复发布。

## 长文

1. 进入“写长文”及新创作入口，填写完整正文与标题，插入指定配图。
2. 需要模板时触发排版，选择用户指定模板；未指定且会显著改变稿件时展示可选结果。
3. 进入发布页，检查独立的摘要/描述字段、封面和排期，不把摘要误当全文。
4. 按授权发布或保存草稿并核验。取消时检查已有内容是否保存，需要且页面提供草稿功能时保存并核对，不把关闭标签页等同已保存。

上游 fill-publish、publish-video、long-article 等 CLI 仅作参考，未接入 Ego，不运行原 Chrome/Bridge 发布器。
