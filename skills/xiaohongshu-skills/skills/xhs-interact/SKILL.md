# 小红书互动

先读 [本机 Ego 执行方式](../../references/local-ego-execution.md)。

1. 核对笔记链接、当前账号和具体动作。回复评论时按作者、原文及上下文定位，不只凭相似文字。
2. 用户文案保留原文；需要拟稿时先给可审阅稿。提交需有本次对相应目标与内容的授权，安装不包含互动授权。
3. 按快照定位正确控件，发送一次或改变一次状态。
4. 评论/回复检查新内容及所属笔记/父评论；点赞/收藏检查状态，计数只作辅助证据。
5. 未知结果先查原状态，避免重复发送或反向切换；平台验证或限制出现时停止并交给用户。

只处理指定目标和数量。批量任务逐项记录成功、失败或未知及原因；读取评论不自动转为互动。
