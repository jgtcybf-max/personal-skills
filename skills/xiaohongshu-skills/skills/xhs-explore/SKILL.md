# 小红书内容发现

先读 [本机 Ego 执行方式](../../references/local-ego-execution.md)。

- 搜索：使用用户关键词及页面可见的排序、类型和时间筛选，记录筛选条件、采集时间、样本数，不把当前搜索结果当作全站完整数据。
- 详情：核对标题、作者、正文、发布时间、媒体类型和可见互动数。链接保留必要的 xsec_token；ID 与 token 必须来自同一作品。
- 评论：区分总数与实际读到条数，需要更多时按页面展开/翻页。只读任务不触发互动。
- 主页：核对账号标识，按请求读取作品列表、简介和公开指标。累计粉丝/获赞不能当作某篇作品或某时段的指标。
- 首页：标明是当前账号当时看到的推荐样本，不推断为全网趋势。

要分析图片时查看实际图片；只取得文字时不声称看懂画面。图片文字读 xhs-images-ocr，复合研究读 xhs-content-ops。输出保留链接、时间与缺口；验证或限流时按 Ego 指南处理。
