# 个人技能库 · Personal Skills

本仓库整理个人制作及在本机改造的 Codex / WorkBuddy 技能，主要用于 AI 影像与视频、女鞋电商、内容运营和日常工作。

技能按原目录保存在 `skills/` 中。每个技能以 `SKILL.md` 为入口，配套脚本、参考资料、模板和已有许可证保留在同一目录。

## 使用方式

1. 找到需要的技能，先阅读其 `SKILL.md`。
2. 将对应完整目录复制到所用客户端的技能目录，例如 Codex 的 `~/.codex/skills/`。
3. 按技能说明安装工具和依赖，并调整本机路径。

这些技能中有 Windows 本机路径、Ego 浏览器要求和特定软件依赖。仓库用于保存和分享技能源文件；文件存在不代表在另一台电脑上已安装依赖、已登录账号或已完成业务验证。

## 来源与范围

- 包含个人创作和本地适配版本；原样安装的第三方技能及系统插件不在本次同步范围。
- 第三方衍生技能保留其上游说明、作者及已有许可证。个人适配不改变原作者归属；详细目录与来源记录见 `CATALOG.md`。
- 仅保存技能文件，排除登录凭据、环境密钥、聊天原文、运行缓存、编译依赖和业务输出。
- 公开可见不等于统一授予开源许可。各目录按其已有许可证与来源声明使用；未附许可证的内容不作额外授权承诺。
